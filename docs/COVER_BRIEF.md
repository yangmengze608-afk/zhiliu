# 封面与 ICON

官方要求：封面 16:9、≤5MB、PNG/JPEG/JPG；ICON 正方形。

## 封面的构图理由

左 700px 深色版面放主张，右侧直接放**真实面板截图**。

**一眼要读到的只有两件事**：这是什么产品（面板长什么样），以及它问了什么问题。
所以封面上没有 API、没有 benchmark、没有架构——那些东西放大了看也不会让人更想点进来。

主文案用的是问句而不是陈述句：

> 你知道自己最近在看什么吗？

副文案补上为什么这是个问题：

> 推荐系统一直在理解你，而你手上没有同一份仪表盘。

第一版把渐变遮罩开到了 34%，正好把面板整个盖住——而面板是这张封面
**唯一必须让人看见的东西**。改成只在接缝处留 5%。

## 截图的诚实边界（重要）

`assets/screenshot-dashboard.png` 里：

- **面板部分是真的**：扩展的真实构建产物渲染的，数字是演示语料跑完整条聚合链路的真实输出
  （与 `node extension/dev/demo-trace.ts` 的最终面板逐字段一致），
  「演示数据」标记是面板**自己**打的，不是后期加的。
- **背景那一页不是 zhihu.com 的抓图**：它是 `extension/dev/shot.html`，
  按知乎版式在本地还原的页面。原因很实际——这张图由自动化流程生成，
  而知乎不允许自动化抓取，我们也没有绕过它的验证。

封面右下角和作品链接页都写明了这一点。
（第一版只有作品链接页写了，封面漏了 —— 而封面恰恰是表单必填项、
评委第一眼看到的东西，也是三处里唯一没带声明的那一处。已补。）**如果你想要一张真实 zhihu.com 的截图**，
那必须由你手动完成：

```bash
# 1. 装 production 包（从公开下载页拿，不依赖仓库路径）
open https://zhiliu-analyze.vercel.app/   # 下载 zhiliu-production.zip，解压后用「加载已解压的扩展程序」装进 Chrome
# 2. 打开一个已验证过的回答页，读够 8 秒让面板出数
# 3. 系统截图（Cmd+Shift+4），存成 assets/screenshot-real.png
```

真人截图会让面板显示「AI 分析」而不是「演示数据」——那张图比现在这张更有说服力。

## ICON 的设计理由

三条长度递减的横条 + 一条带游标的细线 + 一个「知」。

图形不是装饰：那三条横条**就是产品的真实输出形状**（最近窗口里各概念的占比条），
细线是信息集中度。所以缩到 32px 看不清细节时，读到的仍然是"分布"这件事。

刻意不放完整产品名——ICON 在项目卡片上很小，放四个字只会糊成一团。

实测：128 / 48 / 32px 都清楚，16px 时「知」会糊但蓝色占比条仍然可辨。
